# Stage 4 Organization

Status: scaffold only

Stage 4 is reserved for verbatim organization of identified conversation content. The command surface exists, but the implementation is not wired yet.

## Current behavior

- `chronicle organize <session_id>` validates the session.
- The command prepares the Stage 4 output directory under `outputs/<session_id>/stage4/`.
- No production organization artifact is written yet.

## Current limitation

- There is no stable public Stage 4 artifact contract yet.
